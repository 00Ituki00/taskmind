# TaskMind 共有運用ルール

TaskMind をユーザーとエージェントの共有ノートとして使う場合の運用ルール。

## 1. 構造（推奨）

- **親ノード** = 共有テーマ（例：プロジェクト概要 / 論点 / 決定事項）
- **子ノード** = タスク・メモ・質問（担当者、期限、リンク等を `details` に入れる）
- **接続線** = 依存関係・根拠・反論（ラベルで意味を付ける：`なぜ？` / `ただし` 等）
- **グループ** = セクションやサブツリー（縮小/展開・移動が可能）

## 2. 色分け（推奨）

- 🔴 赤系: 要確認・課題
- 🟡 黄系: 生成中・提案中
- 🟢 緑系: 合意済み・完了
- 🔵 青系: 参考・未着手

## 3. 利用ルール

1. **1 ファイルを共有正本** にする（ローカル or Google Drive のいずれか1つ）
2. **ファイル名** は `YYYY-MM-DD_<topic>.json` を推奨（日次運用）
3. **データ構造** は `buildSavePayload()` で統一（`version`, `nodes`, `connections`, `groups`, `nextId`, `customConnectionTypes`）
4. 参照する側は `applyLoadedData()` で読み込む（File / autosave / Drive 経由は統一）
5. **大きくなったらグループ化** して折りたたむ
6. 定期的に **Drive 保存** or ローカル保存でバックアップ（`taskmind_autosave` はローカル側の壊れ防止保険）

## 4. エージェント向け注意

- ノードの `parentId` / `children` の整合性を壊さない
- `details` は自由記述（`why` / `what` / `who` / `where` / `link`）
- グループに含めるノードは「折りたたみ可能なセクション」という用途
- 接続ラベルは **色とアイコン** で意味を付与できる（`customConnectionTypes`）
