# TaskMind - マインドマップ＋タスク管理ツール

## 概要

シンプルかつ多機能なマインドマップ＋タスク管理ツールです。
ノードベースの整理と、入れ子構造によるタスク管理を同時に行えます。

## 特徴

- **ノードベースの整理** - マインドマップのようにノードを配置・接続
- **入れ子タスク** - ノードを別ノードにドラッグして入れ子化。親ノードのタスクリストとして表示
- **チェックボックス** - 各ノードに完了チェックボックスを付与
- **シンプル操作** - ショートカットキー＋ドラッグ操作で直感的に使用
- **複数選択** - Ctrl+クリック / 長押し / 矩形範囲選択で複数ノードを選択
- **接続線** - ノード間に矢印＋ラベル付きの接続線。ホバーで削除ボタン表示
- **レスポンシブ** - PC・スマートフォン両対応
- **データ保存** - JSON形式で保存・読込可能

## 使い方

### 起動
```bash
# 方法1: 直接ブラウザで開く
cd taskmind
start taskmind.html

# 方法2: ローカルサーバーを立てる（推奨）
cd taskmind
python -m http.server 8080
# ブラウザで http://localhost:8080 を開く
```

### 選択

| 操作 | 方法 |
|------|------|
| **単一選択** | ノードをクリック |
| **複数選択（追加）** | Ctrl+クリック / 長押し（モバイル） |
| **範囲選択** | キャンバス上でドラッグ（矩形選択） |
| **全選択解除** | Esc |

### 接続線操作

| 操作 | 方法 |
|------|------|
| **接続作成** | Cキー → 開始ノード → 終了ノード |
| **ラベル編集** | 接続線をクリック |
| **削除** | 接続線にホバーして「×」をクリック / 右クリック |

### 入れ子タスク操作

| 操作 | 方法 |
|------|------|
| **入れ子化** | ノードを別ノードにドラッグ＆ドロップ |
| **完了切替** | チェックボックスをクリック |
| **タイトル編集** | ノードタイトルをダブルクリック |
| **展開/折りたたみ** | ノード右上の ▼/▶ ボタン |
| **親子関係解除** | 右クリックメニュー → 「親子関係を解除」 |

### 編集

- **ノードタイトル** - ダブルクリックして編集
- **チェックボックス** - ノード完了状態を切替
- **ノード色** - ノード左の色ブロックをクリックして変更
- **接続ラベル** - 接続線をクリックしてラベル編集

### 保存・読込

- **保存** - 💾ボタン または Ctrl+S（JSONファイルとしてダウンロード）
- **読込** - 📂ボタン（JSONファイルを選択）

### ショートカットキー

| キー | 機能 |
|------|------|
| Space | パンモード（長押し） |
| V | 選択モード |
| N | ノード追加モード |
| C | 接続モード |
| G | グループ化（複数選択時） |
| Ctrl+クリック | 複数選択（追加/解除） |
| Delete / Backspace | 選択ノード削除（複数対応） |
| Ctrl+S | 保存 |
| Esc | モード解除 / 選択解除 |

## データ形式

保存されるJSONの構造:
```json
{
  "version": 2,
  "nodes": [
    {
      "id": 1,
      "x": 100, "y": 100,
      "title": "ノード名",
      "color": "#e57373",
      "completed": false,
      "expanded": true,
      "parentId": null
    }
  ],
  "connections": [
    { "from": 1, "to": 2, "label": "ラベル" }
  ]
}
```

- 定期的に「保存」ボタンでバックアップを取ることを推奨します
- スマートフォンではタッチ操作に最適化されています
